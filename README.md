# Hackathon Setup Instructions

### Please complete this installation & setup before the hackathon day

1. Install Miniconda from the website: https://www.anaconda.com/download (Windows & Mac users can install their respective versions)

2. Download this entire GitHub repository ([https://github.com/Sandoretal/Hackathon_2025](https://github.com/Sandoretal/Hackathon_2025)) as ZIP, extract it, and place it on the Desktop

3. Open a new VSCode window and navigate to this folder on the Desktop, open it.

4. Open the terminal and run the following commands.

5. `conda env create -f hackathon_env.yml`

6. Activate the environment
   ```
   conda activate hackathon_env
   ```

7. Select the environment manager in the top right corner

8. Press 'Select another environment'

9. Select "Python environments"

10. Select "hackathon_env"
